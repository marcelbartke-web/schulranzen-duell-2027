# Schulranzen-Duell 2026 / 2027

Interaktive, fernsehtaugliche Schulranzen-Auswahl mit echten Produktbildern, Duellrunden und Top 3.

## Nutzung

1. index.html auf einem PC öffnen oder die veröffentlichte Website aufrufen.
2. 2026/2027 und Hersteller auswählen.
3. Zwei Designs vergleichen: links/rechts klicken oder Pfeiltasten verwenden.
4. Platz 1 bis 3 werden durch zusätzliche Entscheidungsrunden ermittelt.
5. Die Ergebnisse bleiben lokal im Browser gespeichert und können kopiert werden.

Produktbilder werden von den jeweiligen Herstellern oder Händlern geladen. Das Design-Ranking ist keine ergonomische Kaufempfehlung. Passform vor Kauf anprobieren. Die Website speichert keine Auswahl auf einem Server.
